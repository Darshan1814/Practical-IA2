# Docker and Kubernetes Practical

## Objective
Containerize a simple web application using Docker and deploy it using Kubernetes.

## Technologies
- Docker
- Kubernetes (K3s)
- Nginx
- AWS EC2
- Ubuntu Linux

## Deployment
1. Build the image using docker build.
2. Run the container using docker run.
3. Import the image into K3s.
4. Apply the Kubernetes Deployment and Service manifests.
5. Verify pods and test the service endpoint.

## Application
A minimal HTML page served through Nginx.
